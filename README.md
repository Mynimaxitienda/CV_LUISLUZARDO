## 🚀 Características Principales

- 🎨 **Estética Neon Warm & Slate Premium**: Interfaz moderna desarrollada con Tailwind CSS v4, paleta en tonos carbón, naranja/ámbar de alta intensidad y bordes traslúcidos con resplandor (*glow effects*).
- 📊 **Métricas y Matriz Radar Interactiva**: Gráficas en tiempo real construidas con **Recharts** (*RadarChart* y *BarChart*) personalizadas en gradientes cálidos para la evaluación técnica.
- ⚡ **Rendimiento React 19 + TypeScript (Strict)**: Renderizado optimizado con Hooks avanzados, tipado estricto y animaciones fluidas impulsadas por **Motion**.
- ☁️ **Muestra de Arquitectura Cloud & BaaS**: Visualizador interactivo de servicios e integración con ecosistemas Google Cloud, Firebase (Firestore, Auth, Hosting) y GitHub Actions (CI/CD).
- 📱 **Diseño 100% Responsivo**: Layout adaptable desktop-first con navegación fluida y menú móvil para cualquier dispositivo.

## ⚡ Instalación y Ejecución Local

### Prerrequisitos
- **Node.js** v18+ 
- **npm** v9+

### Pasos

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/tu-repositorio.git
   cd tu-repositorio
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```

5. **Iniciar en entorno de producción:**
   ```bash
   npm start
   ```
